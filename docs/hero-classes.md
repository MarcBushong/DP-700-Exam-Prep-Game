# Hero classes are discovery filters

The Certification Dungeon uses generic, public industry roles to help learners
find relevant material. A class is not an employer role, credential requirement,
certification bundle, prerequisite, or mandatory learning path.

The data-driven class catalog lives alongside the credential catalog in
`src\content\credentials`. Credentials can belong to several classes. Product
areas and classes organize discovery; they never change an encounter's answer,
objective alignment, difficulty, or score.

| Class                         | Discovery focus                                         |
| ----------------------------- | ------------------------------------------------------- |
| Infrastructure Engineer       | Compute, operations, identity, and infrastructure       |
| Solutions Architect           | Architecture and cross-service design                   |
| Data Engineer                 | Ingestion, transformation, orchestration, and analytics |
| Database Developer            | Data models, database applications, and queries         |
| Software Developer            | Applications, developer tools, and delivery             |
| AI Engineer                   | AI applications, models, and operations                 |
| Application & AI Engineer     | Application development with AI capabilities            |
| Security Engineer             | Protection, governance, and secure engineering          |
| Security Operations Analyst   | Detection, investigation, and response                  |
| Network Engineer              | Connectivity and network design                         |
| DevOps Engineer               | Automation, delivery, and developer workflows           |
| SAP Infrastructure Engineer   | Infrastructure for SAP workloads                        |
| Wanderer (Explore Everything) | Discover without a role filter                          |

Mappings are suggestions, not assertions that every listed credential is active
or has playable content. Sealed and retiring catalog records remain visibly
distinguished. A class selection cannot unlock a dungeon that fails credential,
content, or readiness checks.

Favorite dungeons and the selected class are local preferences. Clearing local
study data removes them; changing classes does not delete completed results.
Dashboard recommendations must explain the observed reason, such as missed
skills in a named dungeon, rather than infer professional competence.
